1. 启动

方式一：双击

F:\MIMO-Space\PEQ-WebUI\启动PEQ-WebUI.cmd

方式二：PowerShell

cd F:\MIMO-Space\PEQ-WebUI
.\start-webui.ps1

或：

py mixer_web.py --port 9100

浏览器打开 http://127.0.0.1:9100/。

启动脚本不会自动 UAC 提权。只有首次把 APO 配置从 C:\Program Files\EqualizerAPO\config 迁到项目内时，才需要一次管理员操作（见第 8 节）。 详细安装坑见《部署手册.md》。
2. 页面与状态

顶部状态通常包括：

  • APO 已安装 / 未安装
  • 配置已托管 / 未接管
  • 设备挂载检测（如 FiiO）
  • 管理员模式 / 普通模式
  • 当前激活预设 / 直通

右上角操作

按钮作用
❓ 帮助在页面内调出用户手册
重启服务重启后端，约数秒后自动刷新
停止服务停止后端；需在本机重新执行启动脚本

常用区域

  • 预设卡片：单击选中，双击激活；可重命名、删除、拖拽排序；pure 固定置顶
  • 曲线图：Raw / Target / EQ / Equalized；拖点改频率与增益，滚轮调 Q，双击空白加 PK
  • EQ 表格 / 手动滑块：精确改类型、频率、增益、Q
  • 目标曲线下拉：Harman / 扩散场 / 平直 / 自定义；选择会写入当前预设
  • 自动拟合开关：换目标/设备时自动拟合并填入草稿
  • 底部：保存到预设 / 保存后立即激活 / 放弃草稿 / 撤销上次保存

测量 rig（同一耳机多版本）

下拉框会按数据源与 rig 标出多版本（oratory / RTINGS / 711 / 5128 等）。 默认推荐 oratory1990。设备 rig 与目标 rig 不同族时会黄色警告，高频结果仅供参考。

3. 新建与激活预设

新建

  1. 点击「+ 新增预设」
  2. 输入名称，可选绑定设备
  3. 创建后进入空预设（默认 Preamp 约 -6 dB）

激活（试听）

  1. 单击卡片选中
  2. 双击激活并写入 APO
  3. APO 检测 hl-active.txt 变化后实时生效
4. 编辑 EQ

加频点

  • 点「+ 添加频段」
  • 曲线空白处双击加 PK；拖点改频率/增益；滚轮改 Q
  • 「导入EQ」粘贴 EqualizerAPO / AutoEq / CSV / JSON 文本后解析并采用草稿

风险提示

底部会提示增益是否偏高，并给出 Preamp 建议，避免削波。

5. 自动拟合与 AutoEq 库

自动拟合

  1. 选择目标曲线（如 Harman 头戴 2018）
  2. 打开「自动拟合」或在拟合页设置滤波器数、频带、最大增益/Q 后预览
  3. 采用为草稿，再保存

快速算法仅需 numpy；安装 scipy 且 AutoEq 就绪时可使用精确引擎。

AutoEq 本地库

  • 「导入原始频响为目标」：把另一副耳机 raw 作为目标
  • 「设备+PEQ」：导入 raw + 预计算 PEQ 到当前预设
需要本机存在 AutoEq 数据目录。默认查找 F:\MIMO-Space\AutoEq-4.1.2\AutoEq-4.1.2， 可用环境变量 AUTOEQ_ROOT 覆盖。
6. 保存、激活与直通
动作结果
保存到预设写入 apo-presets\<id>.txt；若当前已激活则同步激活文件
保存后立即激活写入预设并复制到 apo-config\hl-active.txt
放弃草稿丢弃未保存修改
撤销上次保存从本地 history 恢复上一版（上限约 20 条）

编辑未激活预设时只写仓库文件，不影响当前声音。

8. 首次接管（仅未托管时）

若顶部显示「配置未托管」，说明 APO 仍读 Program Files 原配置。用管理员 PowerShell 执行一次：

cd F:\MIMO-Space\PEQ-WebUI
py -c "from apo_backend import ApoBackend; a=ApoBackend(); a.set_auto_install_enabled(True); print(a.install(by='admin'))"

完成后刷新页面，状态应变为「配置已托管」。之后日常使用不再需要管理员。

接管会改写 config.txt 并可能修改注册表 ConfigPath。 回滚、Peace 共存、设备挂载等细节见《部署手册.md》。
9. 常见问题
问题处理
页面打不开是否已启动；端口 9100 是否被占用；看 err.log
一直未托管按第 8 节管理员接管；检查注册表 ConfigPath
激活了但没声音变化设备是否挂载 APO；是否激活了 pure；播放器是否独占设备
AutoEq 搜不到检查 AUTOEQ_ROOT 与 results\
精确拟合不可用py -m pip install scipy；确认 AutoEq 下有 autoeq\peq.py
想彻底回退见《部署手册.md》§7 卸载/回滚
